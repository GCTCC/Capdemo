# 튜토리얼·퀘스트 데이터 작성 가이드

UI에 나오는 글자와 "언제 뜰지"는 전부 이 폴더(`Assets/Data`)의 에셋에 적습니다. 코드는 고칠 필요가 없어요.
메뉴: **Tools > CapDemo > 데이터**

## 처음 한 번

1. **Tools > CapDemo > 데이터 > 기본 에셋 만들기 (없는 것만)**
   - 키 아이콘표, 거리 설정, 조작 안내, 구역 4개, 말 걸기 안내, 0장 퀘스트 예시가 생겨요.
   - 문구는 시안 v6의 예시예요. Inspector에서 바꿔 쓰면 됩니다.
2. **검사** 메뉴를 눌러 노란 줄을 확인해요. 줄을 누르면 해당 에셋이 선택돼요.

## 폴더

| 폴더 | 들어가는 것 |
|---|---|
| `Areas/` | 구역 (씬 하나에 하나) |
| `Quests/` | 퀘스트 (좌상단 목표) |
| `Guides/` | 첫 안내 (주황 홀로그램 한 번 뜨는 안내) |
| `UI/` | 조작 안내, 키 아이콘표, 거리 설정 (게임에 하나씩) |

새로 만들 때는 Project 창에서 해당 폴더 우클릭 > **Create > CapDemo > 데이터 >** 원하는 종류.
에셋을 만들거나 지우면 게임이 읽는 목록(`Resources/DataCatalog`)은 저절로 다시 채워져요.

## ID 규칙

- 모든 에셋 맨 위의 **Id** 칸. 진행 저장은 파일 이름이 아니라 이 ID로 해요.
- 파일 이름은 마음대로 바꿔도 되지만, **ID는 한 번 정하면 바꾸지 않아요** (바꾸면 그 기록이 끊겨요).
- 영문 소문자·숫자·밑줄과 점: `종류.챕터.이름`

| 종류 | 예 |
|---|---|
| 구역 | `area.livehouse` |
| 퀘스트 | `quest.ch0.enter_livehouse` |
| 목표 지점 | `target.livehouse.bar` |
| 안내 | `guide.talk_first` |
| NPC | `npc.bouncer` |

NPC ID는 씬의 NPC(NpcInteract) Inspector 맨 위 **Npc Id** 칸에 적어요. 비워 두면 예전처럼 동작하지만 퀘스트·안내에서 그 NPC를 가리킬 수 없어요.

## 키 표시 `{F}`

문구에 `{F}`, `{Space}`, `{Up}`처럼 쓰면 그 자리에 키 모양이 들어가요. 쓸 수 있는 이름은 **UI/키아이콘표**에 있고, 줄을 추가하면 새 이름도 쓸 수 있어요. 중괄호 글자 자체를 쓰고 싶으면 `{{`.

## 조건 (공통)

안내·퀘스트·포탈·NPC 새 대화의 "언제"는 모두 같은 **조건 목록**으로 적어요.
- 목록의 조건이 **모두 맞아야** 통과해요. 비어 있으면 항상 통과.
- **아님**을 켜면 반대가 돼요 (예: "안내 봄 + 아님" = 아직 안 봄).

| 종류 | 고르는 값 |
|---|---|
| 튜토리얼 단계 | 단계 + 이상/같음 |
| 퀘스트 상태 | 퀘스트 + 시작 전/진행 중/끝남 (진행 중이면 단계 번호, 0 = 상관없음) |
| NPC 만남 | NPC ID (첫 만남 대화·스토리를 끝까지 봤으면 맞음) |
| 대화·스토리 봄 | 대화 에셋 (끝까지 봤으면 맞음) |
| 안내 봄 | 안내 에셋 |
| 구역 방문 | 구역 에셋 |
| 챕터 클리어 | 숫자 이상 |

## 구역 (Areas)

- **Scene Name**: 씬 이름. 이 씬이 열리면 "방문"으로 저장되고 위치 갱신 홀로그램이 떠요.
- **Show Banner**: 위치 갱신을 언제 띄울지. 들어올 때마다(기본) / 처음 왔을 때만 / 띄우지 않음.
- **Display Name / Top Line / Bottom Line**: 위치 갱신 창의 큰 이름, 위 작은 글자, 아래 정보 줄.
- **Controlled By Otone**: 켜면 통제구역 모양(흰빨강, 감시 중), 끄면 지하 모양(앰버·마젠타, 점선, 낙서).
- **Graffiti**: 지하 모양일 때 낙서 문구.
- **Connected Areas**: 이 씬에서 포탈로 바로 갈 수 있는 구역. 목표가 다른 구역에 있을 때 길 찾기에 써요.

## 퀘스트 (Quests)

- **Start When**: 진행 중인 퀘스트가 없을 때 이 조건이 맞으면 시작. 다른 퀘스트의 Next Quest로 이어지는 퀘스트는 비워 둬요.
- **Steps**: 위에서부터 하나씩. 지금 단계의 **Complete When**이 모두 맞으면 다음 단계로.
  - **Text**: 목표 패널 한 줄.
  - **Target Id / Target Area**: 남은 거리를 잴 목표 지점과 그 구역. 씬에 빈 오브젝트를 만들고 **QuestTarget** 컴포넌트를 붙여 같은 ID를 적어요.
  - **Talk Npc Id**: 이 단계에서 말을 걸 NPC. 그 NPC 위에 노란 !가 떠요.
- **Unknown Text**: 아직 안 열린 다음 단계 자리 문구 (기본 `???`).
- **Next Quest**: 끝나면 바로 이어질 퀘스트. **Clear Chapters**: 끝날 때 챕터 클리어 저장 (튜토리얼 끝 = 1).
- 완료 조건이 빈 단계는 거기서 멈춰요 (검사 메뉴가 알려 줘요).

## 첫 안내 (Guides)

- **Code / Body**: 패널 위 코드(GUIDE · 01)와 본문.
- **Trigger**: 언제 검사할지. 씬 열림 / NPC 범위 / 구역 칸 / 대화 끝 / 퀘스트 단계 변경.
  - NPC 범위: **Trigger Id**에 NPC ID.
  - 구역 칸: 씬에 **ProgressZone**(Box Collider 2D와 함께)을 놓고 같은 ID.
- **Show When / Hide When**: 뜰 조건, 떠 있는 동안 사라질 조건.
- **Once**: 한 번 보면 다시 안 뜸.
- **Point At Npc Id**: 주황 점선으로 가리킬 NPC.

예: 바운서를 처음 만난 뒤 다시 가까이 가면 한 번 → Trigger = NPC 범위, Trigger Id = `npc.bouncer`, Show When = NPC 만남 `npc.bouncer`.

## 조작 안내 (UI/조작안내)

- **Rows**: 키 / 설명 / 오른쪽 라벨. 줄 추가·삭제·순서는 목록에서 바로.
- **Show In Scene**: 이 씬이 열릴 때 한 번 (기본 TutoScene).

## 포탈 (씬의 MapPortal)

- **Destination**: 행선지 구역. 이름표에 그 구역 이름이 보여요 (**Label Override**로 바꿀 수 있음).
- **Button Text**: 버튼 문구 (들어가기).
- **Open When / Locked Text**: 열리는 조건과 잠겼을 때 문구.
- Target Scene을 비우면 Destination 구역의 씬으로 가요.

## NPC 새 대화 (씬의 NpcInteract)

- **New Dialogues**: 조건이 맞으면 평소 대사 대신 나오는 대화. 조건이 맞고 아직 안 봤으면 빨간 말풍선 •••이 떠요.

## 진행 저장과 테스트

- 저장 파일: `save.json` 하나 (**저장 파일 폴더 열기**). 메모장으로 열어 볼 수 있어요.
- **진행 확인**: 지금 저장 상태를 콘솔에 한 줄로.
- **진행 초기화**: 처음 상태로 (설정값은 그대로).
- **지금 퀘스트 단계 건너뛰기 (Play 중)**, **선택한 퀘스트 처음부터 시작 (Play 중)**.
- 맵 씬을 바로 Play할 때 튜토리얼 단계는 **Tools > CapDemo > 튜토리얼 테스트**에서 골라요. "저장된 단계 그대로"를 고르면 save.json의 단계를 써요.
