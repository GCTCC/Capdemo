# 맵 작업 가이드

구역 하나 = 씬 하나. 씬마다 큰 배경 한 장 위에 오브젝트·NPC를 하나씩 놓고, 포탈로 다른 구역 씬과 잇는다.

## 처음 한 번

1. `Tools > CapDemo > 데모 > 플레이어 애니메이션 적용` (이미 했다면 생략)
2. `Tools > CapDemo > 맵 > 맵 부품 준비`
   - 그림 폴더 `Assets/image/Map/Backgrounds`, `Objects`, `NPCs`
   - 프리팹 `Assets/Prefabs/Map` (Player, DialogueCanvas, MapObject, NPC, Portal, SpawnPoint)
   - 대사 폴더 `Assets/Dialogue`
   - 그리기 순서(Sorting Layer): Background → Map → MapFront (오른쪽일수록 앞). 배경을 뺀 오브젝트·NPC·플레이어는 모두 Map 한 층에 있고, 앞뒤는 Order 숫자로 정한다.

프리팹은 없을 때만 만들어지니, 프리팹을 직접 고쳐도 다시 실행했을 때 덮어써지지 않는다.

## 새 구역 만들기

`Tools > CapDemo > 맵 > 새 구역 씬 만들기` → 이름 입력 (예: `Area_Market`)

카메라, 플레이어, 대화창, 빈 그룹(Background, Objects, NPCs, Portals), 도착 지점 `Start`가 들어 있는 씬이 `Assets/Scenes/Map`에 만들어지고, 빌드 씬 목록에도 자동으로 들어간다.

## 그림 넣기

그림 파일은 `Assets/image/Map`의 알맞은 폴더에 넣는다. 처음 들어올 때 도트 설정(Point 필터, 압축 없음)이 자동으로 들어간다.

- Objects·NPCs 그림은 플레이어와 같은 비율(PPU 128, 256px 그림이 2유닛)이고, 기준점이 발밑이라 바닥에 놓기 쉽다.
- 크기가 안 맞으면 그림을 선택하고 Inspector의 Pixels Per Unit을 바꾼다. 한 번 바꾼 설정은 그대로 유지된다.

## 배경

`Background`는 맵의 틀(범위·바닥·벽)과 배경 그림을 함께 맡는다.

1. Hierarchy에서 `Background` 선택
2. 배경 그림을 Inspector의 `Map Background` > Image 칸에 끌어다 놓는다 (높이는 자동으로 맵 높이에 맞춰진다)
3. 값 정하기:
   - Map Length: 맵 가로 길이. 화면 하나가 약 17.8유닛. 씬 화면의 **노란 상자**가 맵 범위다.
   - Map Offset: 맵 범위(노란 상자)를 좌우로 옮긴다. 0이면 Background 위치가 맵 가운데다. 배경 그림은 그대로 두고 범위·바닥·벽·카메라 한계만 옮겨지므로, 그림에 맞춰 맵이 시작하는 자리를 정할 때 쓴다.
   - Height: 맵 높이 (기본 10 = 화면 높이)
   - Ground Height: 맵 아래끝에서 바닥까지 높이. Background를 선택하면 보이는 **초록 선**이 바닥과 벽이다.
   - Walls: 양쪽 끝 보이지 않는 벽

카메라는 노란 상자 밖을 보여 주지 않는다.

배경 그림은 맵보다 짧아도 된다. 플레이 중에는 카메라보다 천천히 움직여서, 맵 왼쪽 끝에서는 그림 왼쪽 끝이, 오른쪽 끝에서는 그림 오른쪽 끝이 보인다(멀리 있는 것처럼 보이는 효과). 편집 화면에서는 그림이 맵 가운데에 고정돼 보인다.

### 배경 여러 장 이어 붙이기 (실내 등)

`Map Background` > Layout을 **여러 장 이어 붙이기 (고정)** 으로 바꾸고, Images 목록에 `+`로 칸을 늘려 그림을 왼쪽부터 순서대로 넣는다.
그림마다 높이가 Image Height에 맞춰지고 빈틈없이 옆으로 이어지며, 움직이지 않는다. Fit Length To Images를 켜면 맵 길이(노란 상자)가 그림 폭의 합으로 맞춰진다(켜 두면 Map Length를 바꿔도 돌아간다).

배경 크기는 맵 높이와 따로 정할 수 있다. Image Height로 그림 높이를(Height와 별개), Image Offset으로 위치를 조정한다. 기본은 그림 아래끝이 맵 아래끝에 붙는다.

### 한 장 방식일 때

그래서 **바닥 그림과 오브젝트는 맵 길이만큼 직접 깐다.** 바닥 그림은 MapObject 하나를 만들어 `Ctrl+D`로 복제해 옆으로 붙이면 된다. 충돌은 초록 선이 맡으니 바닥 그림의 Solid는 꺼 둬도 된다.

## 맵 오브젝트

1. `Assets/Prefabs/Map/MapObject`를 Hierarchy의 `Objects` 아래로 끌어다 놓는다
2. Sprite 칸에 그림을 넣는다 (언제든 바꿀 수 있다)
3. `Map Object`의 값:
   - Solid: 체크하면 밟거나 부딪힌다. 충돌 상자는 그림 크기에 자동으로 맞춰진다.
   - Order: 앞뒤 순서. **플레이어는 0**이다. 음수면 플레이어 뒤, 양수면 앞. 오브젝트·NPC끼리도 클수록 앞에 그린다.
     예) 선반 -5, 플레이어 0, 기둥 3 → 선반과 기둥 사이로 플레이어가 지나간다.
4. 바닥에 딱 붙이려면 오브젝트를 선택하고 `Tools > CapDemo > 맵 > 선택한 오브젝트 바닥에 붙이기`

## NPC

1. `Assets/Prefabs/Map/NPC`를 `NPCs` 아래로 끌어다 놓고 Sprite 칸에 그림을 넣는다
2. 대사 파일 만들기: `Assets/Dialogue`에서 우클릭 > `Create > CapDemo > NPC 대화` → 이름 정하기 (예: `대화_상인`)
3. 대사 파일을 선택해 Lines에 대사를 적는다 (Speaker = 이름표, Text = 대사, 스토리와 같은 형식)
4. NPC의 `Npc Interact` > Dialogue 칸에 대사 파일을 끌어다 놓는다

같은 대사 파일을 여러 씬의 NPC가 같이 써도 된다. 대화창 모양은 모든 NPC가 같은 `DialogueCanvas`를 쓴다.
말을 걸 수 있는 범위는 `Npc Layout` > Talk Width로 조절한다.
앞뒤 순서는 `Npc Layout` > Order로 정한다(맵 오브젝트와 같은 기준, 플레이어 0).

### 첫 만남 강제 대화

처음 다가갔을 때 F 없이 대화가 시작되고, 그 뒤로는 F로 다른 대사가 나오게 할 수 있다.

1. 대사 파일을 두 개 만든다: 첫 만남용(예: `대화_상인_첫만남`)과 평소용(예: `대화_상인`)
2. NPC의 `Npc Interact`에서
   - Dialogue: 평소용 파일 (F로 말을 걸 때)
   - First Meet Dialogue: 첫 만남용 파일
   - First Meet Distance: NPC 중심에서 이 가로 거리(유닛) 안으로 들어오면 대화가 시작된다. NPC를 선택하면 씬 화면에 **주황 세로선**으로 보인다.
3. 첫 만남 대화를 끝까지 보면 기록이 남아(게임을 껐다 켜도 유지) 다시는 강제로 나오지 않는다.

- 기록은 첫 만남 대사 **파일 이름**으로 한다. NPC마다 다른 파일을 쓰고, 만든 뒤에는 이름을 바꾸지 않는다(바꾸면 처음 만나는 것으로 친다).
- 다시 처음부터 시험하려면 `Tools > CapDemo > 플레이 데이터 초기화`를 누른다(튜토리얼·이름 기록과 함께 지워진다).
- First Meet Dialogue를 비워 두면 예전처럼 F로만 말을 건다.

### 조명 그림자

플레이어·NPC에는 `Character Shadow`가 붙어 있어 가짜 그림자를 그린다(Unity 2D 그림자는 옆에서 보는 맵에서 광원과 겹치면 어색해서 쓰지 않는다).
- 발밑 그림자: 바닥에 깔리는 옅은 타원. 가까운 조명이 있으면 진해지고 조명 반대쪽으로 조금 밀린다.
- 벽 그림자: 캐릭터 모양 그림자가 배경에 옅게 비친다. 가장 가까운 조명 반대쪽으로 밀리고, 멀어질수록 흐려진다.
- 그림자를 만드는 조명은 **Shadows가 켜진 Spot(Point) Light 2D**다. 조명마다 Shadows를 끄면 그 조명은 그림자를 만들지 않는다.
- 진하기·밀리는 거리·조명이 닿는 거리(Light Reach)는 프리팹의 `Character Shadow`에서 조절한다.

예전에 만든 구역은 `Tools > CapDemo > 맵 > 예전 맵 업데이트 (그리기 순서 한 층으로·캐릭터 그림자)`를 한 번 누르면 지금 방식으로 바뀐다(보이는 앞뒤는 그대로 유지).

## 다른 구역으로 넘어가기

1. 넘어갈 씬에 도착 지점을 둔다: `Assets/Prefabs/Map/SpawnPoint`를 놓고 Id를 정한다 (예: `FromMarket`)
2. 출발 씬에 `Assets/Prefabs/Map/Portal`을 놓는다
   - Target Scene: 넘어갈 씬 이름 (예: `Area_Station`)
   - Target Spawn: 그 씬의 도착 지점 Id
   - Need Key: 체크하면 ↑/W를 눌러야 넘어간다(문). 끄면 닿자마자 넘어간다(맵 끝).
3. 포탈 크기는 Box Collider 2D의 Size로 조절한다 (씬 화면에 파란 상자로 보인다)

주의: 도착 지점을 그 씬의 포탈 범위 안에 두면 도착하자마자 다시 넘어간다. 포탈에서 조금 떨어뜨려 둔다.
씬을 직접 플레이하면 플레이어는 씬에 놓인 자리에서 시작한다.
