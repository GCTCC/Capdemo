# 맵 작업 가이드

구역 하나 = 씬 하나. 씬마다 큰 배경 한 장 위에 오브젝트·NPC를 하나씩 놓고, 포탈로 다른 구역 씬과 잇는다.

## 처음 한 번

1. `Tools > CapDemo > 데모 > 플레이어 애니메이션 적용` (이미 했다면 생략)
2. `Tools > CapDemo > 맵 > 맵 부품 준비`
   - 그림 폴더 `Assets/image/Map/Backgrounds`, `Objects`, `NPCs`
   - 프리팹 `Assets/Prefabs/Map` (Player, DialogueCanvas, MapObject, NPC, Portal, SpawnPoint)
   - 대사 폴더 `Assets/Dialogue`
   - 그리기 순서(Sorting Layer): Background → MapBack → Characters → MapFront (오른쪽일수록 앞)

프리팹은 없을 때만 만들어지니, 프리팹을 직접 고쳐도 다시 실행했을 때 덮어써지지 않는다.

## 새 구역 만들기

`Tools > CapDemo > 맵 > 새 구역 씬 만들기` → 이름 입력 (예: `Area_Market`)

카메라, 플레이어, 대화창, 빈 그룹(Background, Objects, NPCs, Portals), 도착 지점 `Start`가 들어 있는 씬이 `Assets/Scenes/Map`에 만들어지고, 빌드 씬 목록에도 자동으로 들어간다.

## 그림 넣기

그림 파일은 `Assets/image/Map`의 알맞은 폴더에 넣는다. 처음 들어올 때 도트 설정(Point 필터, 압축 없음)이 자동으로 들어간다.

- Objects·NPCs 그림은 플레이어와 같은 비율(PPU 128, 256px 그림이 2유닛)이고, 기준점이 발밑이라 바닥에 놓기 쉽다.
- 크기가 안 맞으면 그림을 선택하고 Inspector의 Pixels Per Unit을 바꾼다. 한 번 바꾼 설정은 그대로 유지된다.

## 배경

1. Hierarchy에서 `Background` 선택
2. 배경 그림을 Inspector의 Sprite Renderer > Sprite 칸에 끌어다 놓는다
3. 높이가 화면에 자동으로 맞춰진다. `Map Background`의 값:
   - Height: 배경 높이 (기본 10 = 화면 높이)
   - Ground Height: 그림 아래끝에서 바닥까지 높이. Background를 선택하면 보이는 초록 선이 바닥과 벽이다. 그림 속 바닥에 맞춰 조절한다.
   - Walls: 양쪽 끝 보이지 않는 벽

카메라는 배경 밖을 보여 주지 않는다.

## 맵 오브젝트

1. `Assets/Prefabs/Map/MapObject`를 Hierarchy의 `Objects` 아래로 끌어다 놓는다
2. Sprite 칸에 그림을 넣는다 (언제든 바꿀 수 있다)
3. `Map Object`의 값:
   - Solid: 체크하면 밟거나 부딪힌다. 충돌 상자는 그림 크기에 자동으로 맞춰진다.
   - Depth: 캐릭터 뒤 / 캐릭터 앞
   - Order: 같은 쪽끼리 겹칠 때 클수록 위
4. 바닥에 딱 붙이려면 오브젝트를 선택하고 `Tools > CapDemo > 맵 > 선택한 오브젝트 바닥에 붙이기`

## NPC

1. `Assets/Prefabs/Map/NPC`를 `NPCs` 아래로 끌어다 놓고 Sprite 칸에 그림을 넣는다
2. 대사 파일 만들기: `Assets/Dialogue`에서 우클릭 > `Create > CapDemo > NPC 대화` → 이름 정하기 (예: `대화_상인`)
3. 대사 파일을 선택해 Lines에 대사를 적는다 (Speaker = 이름표, Text = 대사, 스토리와 같은 형식)
4. NPC의 `Npc Interact` > Dialogue 칸에 대사 파일을 끌어다 놓는다

같은 대사 파일을 여러 씬의 NPC가 같이 써도 된다. 대화창 모양은 모든 NPC가 같은 `DialogueCanvas`를 쓴다.
말을 걸 수 있는 범위는 `Npc Layout` > Talk Width로 조절한다.

## 다른 구역으로 넘어가기

1. 넘어갈 씬에 도착 지점을 둔다: `Assets/Prefabs/Map/SpawnPoint`를 놓고 Id를 정한다 (예: `FromMarket`)
2. 출발 씬에 `Assets/Prefabs/Map/Portal`을 놓는다
   - Target Scene: 넘어갈 씬 이름 (예: `Area_Station`)
   - Target Spawn: 그 씬의 도착 지점 Id
   - Need Key: 체크하면 ↑/W를 눌러야 넘어간다(문). 끄면 닿자마자 넘어간다(맵 끝).
3. 포탈 크기는 Box Collider 2D의 Size로 조절한다 (씬 화면에 파란 상자로 보인다)

주의: 도착 지점을 그 씬의 포탈 범위 안에 두면 도착하자마자 다시 넘어간다. 포탈에서 조금 떨어뜨려 둔다.
씬을 직접 플레이하면 플레이어는 씬에 놓인 자리에서 시작한다.
